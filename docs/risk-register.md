Update this table as risks are validated, mitigated, or newly discovered —
do not delete history; mark rows as resolved with the evidence.

risk descriptions; statuses reflect implemented mitigations and actual limits.

## Rollback strategy

Phase 0 made no source changes. ADR-001's independent module boundaries
allow focused rollback without rewriting protected STT/Windows sources, but
they are not permission to delete today's dirty/untracked work. Restore kept
matching native binaries/wheels or build a reviewed earlier revision in a
separate source directory; see [installation](installation.md#rollback).
Shared installer changes require independent review. Any Git revert is a
separately authorized, scoped action against a known committed change, not a
reset/clean of the current checkout.
